# 建材询盘背调工作包

面向玻璃马赛克、瓷砖及装饰板材外贸业务。把海外询盘表整理成客户名单、联系方式与证据、排除记录，供外贸员跟进。

[打开下载页](https://mio4038.github.io/research.skill/) · [下载 Codex 工作包](https://mio4038.github.io/research.skill/workkit.zip)

## 外贸员使用方法

1. 下载 ZIP 并解压，在 Codex 桌面版打开解压后的 `workkit` 文件夹。
2. 在新对话中附上 XLSX 或 CSV 询盘表，发送下方指令。首次使用建议先试跑十条。
3. 看完预审结果后，如需验证新邮箱，在自己的 Codex 环境连接公司授权的 Apollo 账号，再确认本批邮箱数量和最高额度。
4. 领取 Excel 或 CSV。优先查看浅黄色客户行，由外贸员联系客户并记录反馈。

> 使用 $building-lead-review 处理附件。按原表顺序筛选，保留证据和进度。先出预审表与额度清单。

## 筛选和验证规则

- 先剔除 homeowner 并去重。明显不匹配或首轮仍无法归属到具体经营主体的线索，停止扩搜。
- 通过初筛后，再核对官网、产品、公开联系方式、工商及社交资料，以及可见的中国贸易记录。
- 联系方式保留来源和获取时间。历史邮箱验证可复用。Apollo 未确认的邮箱保留原状态，电话记录公开来源和格式检查结果。
- 页面的下载包只包含流程规则、脚本、操作说明和虚构样例。实际询盘、背调缓存及验证记录留在本地 `local-data/`，通过公司内部渠道交接。对外联系由外贸员发起。

## 仓库维护

`index.html` 是下载页，`workkit.zip` 是可分发的工作包。更新流程时，应同步更新 ZIP 和页面说明。GitHub Pages 从 `main` 分支根目录发布，部署设置见 [PAGES.md](PAGES.md)。
