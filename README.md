# 建材询盘背调工作包

这是一个可在 Codex 中使用的工作包，适合整理玻璃马赛克、瓷砖和装饰板材的海外询盘。导入表格后，可得到按优先级标记的客户名单、带来源的联系方式，以及暂不跟进的记录。

[打开下载页](https://mio4038.github.io/research.skill/) · [下载 Codex 工作包](https://mio4038.github.io/research.skill/workkit.zip)

## 快速开始

1. 下载 ZIP 并解压，在 Codex 桌面版打开解压后的 `workkit` 文件夹。
2. 在新对话中附上 XLSX 或 CSV 询盘表，发送下方指令。首次使用建议先试跑十条。
3. 查看预审结果。如需验证新邮箱，可连接获授权的 Apollo 账号，并确认本批邮箱数量和最高额度。
4. 导出 Excel 或 CSV。按 A、B、C、D 查看跟进优先级，可在结果表中记录后续联系和反馈。

> 使用 $building-lead-review 处理附件。按原表顺序筛选，保留证据和进度。先出预审表与额度清单。

## 筛选和验证规则

- 排除个人商家、个人自用、重复以及补查后仍无可用线索的条目。能确认主体的企业继续查询，即使主营业务与建材有距离。
- 核对官网、主营、公开渠道及实际采购或项目线索。A 表示已有明确采购证据，B 表示渠道直接相关，C 表示主营较远但有相关需求线索，D 表示企业可核实且相关需求待确认。
- 对新增客户的联系方式核对来源。新增邮箱按批确认后验证，历史结果直接复用。主表采用统一白灰样式，只列结论和状态。
- 下载包含流程规则、脚本、操作说明和虚构样例。实际询盘、背调缓存和验证记录存放在本地 `local-data/`。如需共享，使用团队内部渠道。

## 仓库维护

`index.html` 是下载页，`workkit.zip` 是可分发的工作包。更新流程时，应同步更新 ZIP 和页面说明。GitHub Pages 从 `main` 分支根目录发布，部署设置见 [PAGES.md](PAGES.md)。
