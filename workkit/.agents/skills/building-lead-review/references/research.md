# 搜索范围与逐字段收尾

先查看旧报告、来源、时间和历史验证结果。用法律名称及国家、注册号、独立域名、原联系方式等交叉确定归属。共享总机、免费邮箱、同名公司和集团关系都不足以单独合并主体。没有旧证据时按下列路径搜索。已有可靠结果或曾充分核查且没有新线索的字段直接复用，保留原日期。

1. **主体**：公司名加国家或城市。优先官网与当地工商登记。泛称或同名时用原电话、邮箱域名、联系人、名称变体或当地语言反查。主体仍无法归属且没有可用经营线索时标为无可用线索。工具报错或出现多个尚未消歧的候选时标为待查，保留本地进度。
2. **官网、主营和类型**：查询公司官网、About、产品目录、项目页及登记业务。搜索时即使主营与建材较远，也结合原询盘核对装修、项目、自用或转售场景。原询盘需求和第三方证据分开。企业能归属即保留，主营只影响评级。独立官网确认不了时可留公开企业主页作为证据。
3. **地址、联系人和社交**：在官网 Contact、页脚或法律声明找地址，缺失时补工商登记和地图或可信商业名录。标明注册地址、实际办公地、门店、邮寄地址或仅城市。有冲突时按来源分别记录，不能把邮政信箱当街址。LinkedIn、Facebook 可补正式公司页或公开人员角色。不要用团队成员的旧任职资料绑定当前询盘。
4. **邮箱与电话**：先提取官网、登记或可信商务出处的公开联系方式。原询盘值保留原表位置。检查是否同一主体，电话标准化为可确认的国际格式，并注明是否有公开来源支持。格式检查与是否在网、能接通分别记录。不得从姓名和域名猜邮箱。
5. **进出口**：用法律名或可确认的别名查 ImportGenius、Panjiva、可公开访问的贸易平台。记录可见的主体、贸易方向、国家、产品、日期和对应 URL。核实集团或同名噪音。历史中国来源五金、机械等可记录，按实际品类与目标建材区分。公开未命中写“公开范围未检出”。网页或数据库无法访问时保留查询障碍。
6. **完整性**：在本地逐字段标记已取得、未确认、待查、不适用。空白不构成完成。同一字段可按“官网或项目页 → 工商/地图/可信目录 → 当地语言或反查”走一遍，出现充分证据就停止。简短记录查询式、来源、时间和决定。导出前用脚本列出未完成字段，只补缺项，避免把摘要当成所有字段都查过。

评级：A 有可归属的相关采购、项目需求或进口证据。B 产品或施工渠道直接相关，采购计划尚待确认。C 主营较远但有相关需求或可核实的采购场景。D 企业主体可确认，目前缺少相关需求证据。评级独立于邮箱状态。
